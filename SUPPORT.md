# Support

DragonForge Asset Vault is an active development/maintenance project and public portfolio repository candidate, not a commercial support service.

For ordinary bugs, documentation problems, or feature ideas, use the repository's GitHub issue templates when issues are publicly available. Include the affected commit/version, operating system, reproduction steps, and sanitized logs where useful.

Do not upload proprietary assets, licensed third-party content, credentials, tokens, private keys, personal data, private repository contents, or security exploit details. Use synthetic/demo assets where reproduction material is needed. Vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md).

Unsolicited code or asset contributions are not currently accepted; see [CONTRIBUTING.md](CONTRIBUTING.md).
